# API REST - Sistema de Gestion de Gimnasio
 Desarrollada con Java y Spring Boot que es el stack tecnologico principal, Docker que es para desplegar los contenedores y despliegue del sistema 
 lo cual nos permitira gestionar de manera eficiente las operaciones principales 
 de un gimnasio: administracion de socios, entrenadores, clases, inscripciones, control de cupos, registro de asistencia y pagos.

 Descripción del Proyecto:
  el sistema permite administrar el flujo completo de un gimnasio.

 . administración de socios y entrenadores
 . gestion de clases e incripciones
 . control de cupos
 . registro de asistencia
 . control de pagos
